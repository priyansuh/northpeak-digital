# NorthPeak Digital

A responsive digital agency website built with HTML, CSS, and JavaScript.

## 🌐 Live Website

[Visit NorthPeak Digital](https://priyansuh.github.io/northpeak-digital/)

## ✨ Features

- Responsive design for desktop and mobile devices
- Mobile-friendly hamburger navigation menu
- Services section highlighting digital services
- About section introducing NorthPeak Digital
- Pricing plans section
- Contact section with an email button
- Interactive navigation using JavaScript

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Git and GitHub
- GitHub Pages

## 📱 Responsive Design

The website is designed to work on desktop and mobile screens. The mobile navigation menu can be opened using the hamburger button and closed using the close icon or by selecting a navigation link.
